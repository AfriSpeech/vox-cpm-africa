# VoxCPM Africa 🌍

**VoxCPM Africa** is an adaptation of [VoxCPM-0.5B](https://huggingface.co/openbmb/VoxCPM-0.5B) for **African languages and English**, fine-tuned on the 897-hour [AfriSpeech](https://huggingface.co/datasets/AfriSpeech/african-speech-tts-aligned) dataset using phonetic IPA representations generated by [africa-g2p](https://github.com/AfriSpeech/africa-g2p) on an NVIDIA H200 GPU.

Developed and maintained by the **AfriSpeech** team.

---

## Architecture

* **Backbone:** MiniCPM-0.5B autoregressive speech backbone.
* **Acoustic Head:** AudioVAE (`audiovae.pth`) with continuous flow-matching / diffusion head for high-fidelity speech synthesis.
* **Phonetic IPA Processing:** Powered by `africa-g2p` to eliminate orthographic ambiguity across 93 African languages.
* **Zero-Shot Voice Cloning:** Clone any voice using a 3–5s reference clip.


## Quickstart Inference

```python
from voxcpm_africa.infer import VoxCPMAfrica
import soundfile as sf

tts = VoxCPMAfrica()

# 1. Zero-shot Speech Synthesis with Automatic African IPA
audio = tts.generate(
    text="Akwaaba! Yɛfrɛ me Kofi, mepɛ sɛ mereka Twi kyerɛ wo nnɛ.",
    language="twi",
)
sf.write("twi_voxcpm.wav", audio, tts.sampling_rate)

# 2. Voice Cloning
cloned = tts.generate(
    text="Sannu da zuwa! Ina fatan kuna lafiya.",
    language="hau",
    ref_audio="path/to/reference_voice.wav",
)
sf.write("hausa_cloned.wav", cloned, tts.sampling_rate)
```

## Training Pipeline on H200

```bash
# 1. Prepare and slice audio manifest from the African corpus:
python -m scripts.prepare_african_dataset \
    --input_jsonl "/mnt/volume_d2wey28/data/africa-tts/train_final.jsonl" \
    --output_manifest "/mnt/volume_d2wey28/data/vox-cpm-africa/train_manifest.jsonl"

# 2. Launch detached fine-tuning:
bash scripts/run_train.sh
```
